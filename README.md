🌱 Plant Care & Treatment

📌 Project Description

Plant Care & Treatment is a simple web-based application designed to help users take better care of their plants. It provides useful information about basic plant care and gives simple treatment suggestions for common plant problems.

Users can select a plant problem such as yellow leaves, brown spots, pests, or wilting, and the website provides a suitable treatment suggestion.

🎯 Objectives

- To provide basic information about plant care.
- To help users understand common plant problems.
- To provide simple treatment suggestions.
- To create an easy-to-use and interactive website.
- To promote healthy plant growth.

✨ Features

- 🌿 Basic plant care information
- 💧 Watering guidance
- ☀️ Sunlight guidance
- 🌱 Soil information
- 🌾 Fertilizer guidance
- 🩺 Common plant problem selection
- 💊 Treatment suggestions
- 🖥️ Simple and user-friendly interface

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Select a plant problem from the Treatment section.
5. Click Get Treatment to view the suggestion.

🩺 Plant Problems Covered

Problem| Treatment
Yellow Leaves| Check watering and sunlight
Brown Spots| Remove affected leaves and avoid excess moisture
Pests| Remove pests and use suitable natural treatment
Wilting| Check soil moisture and provide adequate water
